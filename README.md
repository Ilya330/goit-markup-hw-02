# goit-markup-hw-02

Домашнє завдання №2: семантична розмітка та базові текстові стилі сторінки WebStudio.

## Перегляд

Відкрийте `index.html` у браузері. Для завантаження Google Fonts і modern-normalize потрібне інтернет-з’єднання.

## Структура

- `index.html` — шапка, Hero, Features, Team, Portfolio та підвал.
- `css/main.css` — підключення стилів через `@import`.
- `css/common.css` — загальні стилі та логотип.
- `css/header.css`, `hero.css`, `features.css`, `team.css`, `portfolio.css`, `footer.css` — стилі відповідних частин сторінки.
- `images/` — зображення команди та портфоліо.

Відступи та розміри блоків не додаються відповідно до вимог другого модуля.
